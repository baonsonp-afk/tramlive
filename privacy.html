Privacy Policy – Tram Live

Last updated: 5 November 2026

Tram Live is a desktop application that runs only on its owner's computer. When the owner authorizes a YouTube channel, the app receives an OAuth token from Google and stores it locally on that computer. The token is used only to create and manage live broadcasts, live streams and thumbnails on the authorized channel.

Tram Live does not send any data to servers other than Google/YouTube, does not sell or share data, and does not collect information about viewers or any other users. YouTube data obtained through the API is used only to operate the owner's own channels.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Tram Live uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Access can be revoked at any time at myaccount.google.com/permissions; the owner can delete the local token file at any time.
